## Sobre o Projeto

O IntegraLog é um sistema web desenvolvido para otimizar o gerenciamento logístico de remessas de materiais de expediente destinadas ao Tribunal de Justiça do Estado do Rio Grande do Sul (TJRS).

Atualmente, o processo de controle das entregas é realizado de forma manual por meio de documentos físicos denominados Guias de Remessa. Esse método apresenta limitações relacionadas à rastreabilidade das entregas, atualização de informações e armazenamento dos comprovantes de recebimento.

O sistema proposto tem como objetivo digitalizar e centralizar o controle logístico, permitindo o acompanhamento completo das remessas desde a coleta dos materiais até a confirmação da entrega.

A plataforma é composta por dois módulos principais:

1. Painel Administrativo: Utilizado para cadastro, consulta e gerenciamento das remessas.
2. Portal Mobile para Motoristas: Responsável pelo envio fotográfico dos comprovantes de entrega diretamente pelo dispositivo móvel.

---

## Tecnologias Utilizadas

- Linguagem Backend: PHP
- Frontend: HTML5, CSS3 e JavaScript
- Banco de Dados: MySQL / MariaDB
- Servidor Local: XAMPP
- Hospedagem Web
- Desenvolvimento Responsivo para Desktop e Dispositivos Móveis

---

## Funcionalidades Principais

### 1. Gerenciamento de Remessas

- Cadastro de novas remessas de materiais de expediente.
- Registro das informações da Guia de Remessa.
- Consulta de remessas cadastradas.
- Acompanhamento do status logístico das entregas.

### 2. Painel Administrativo

- Visualização completa das remessas registradas.
- Atualização do andamento das entregas.
- Consulta de comprovantes enviados pelos motoristas.
- Controle centralizado das operações logísticas.

### 3. Portal Mobile para Motoristas

- Acesso através de dispositivos móveis.
- Envio fotográfico das Guias de Remessa assinadas.
- Registro digital do comprovante de entrega.
- Integração imediata com o sistema administrativo.

### 4. Rastreabilidade das Entregas

- Controle completo do ciclo de transporte.
- Histórico das movimentações realizadas.
- Armazenamento digital dos comprovantes.
- Redução do risco de extravio de documentos físicos.

### 5. Segurança da Informação

- Utilização de consultas parametrizadas para prevenção de SQL Injection.
- Controle de acesso às funcionalidades do sistema.
- Armazenamento seguro das informações e comprovantes enviados.

---

## Benefícios da Solução

- Digitalização do processo logístico.
- Maior controle sobre as entregas realizadas.
- Redução do uso de documentos físicos.
- Agilidade na atualização das informações.
- Melhor rastreabilidade das remessas.
- Centralização das informações em ambiente web.
- Facilidade de acesso tanto para administradores quanto para motoristas.
